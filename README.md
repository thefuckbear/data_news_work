# 通勤贫困：当代都市青年的“第二份工”

这是一个围绕城市青年长距离通勤问题制作的交互式数据新闻网页。项目综合 2020—2023 年主要城市通勤数据，从通勤时间、职住分离、住房成本、行业收入和身心影响等角度，讨论“通勤贫困”如何成为都市青年的时间成本与生活压力。

## 在线阅读

**[点击进入交互式数据新闻网页](https://thefuckbear.github.io/data_news_work/)**

项目使用 GitHub Pages 部署，无需安装软件，使用现代浏览器即可访问。页面包含滚动叙事、数据图表、交互式可视化和移动端适配。

## 选题说明

网页将长时间通勤描述为都市青年的“第二份工”：劳动时间之外，通勤者还要持续支付时间、交通、住房选择和身心健康成本。

项目主要回答以下问题：

1. 哪些青年群体更容易承受长时间通勤？
2. 城市扩张和职住分离为什么会增加极端通勤？
3. 收入、行业和住房成本如何影响通勤选择？
4. 长时间通勤如何影响幸福感、睡眠、工作表现与职业发展？
5. 城市规划、企业制度和公共交通可以提供哪些改善路径？

## 页面内容

### 通勤现状

以主要城市平均通勤时间、通勤距离和 60 分钟以上极端通勤人口比例作为问题入口，说明通勤如何持续占用劳动者的日常时间。

### 群体画像

页面从学历、行业、收入、租金和月通勤成本等维度描述长时间通勤者。其中，页面展示的调查数据包括：本科学历者占 74.7%，大专学历者占 14.8%，大专及以上青年接近长时间通勤群体的九成。

### 形成原因

项目将城市空间扩张、核心就业区与外围居住区分离、住房成本差异和收入约束联系起来，解释青年为什么会以更长通勤时间换取较低居住成本。

### 个体与社会影响

页面讨论长时间通勤对睡眠、情绪、工作效率、职业流动和城市活力的影响，并通过图表展示通勤时间与生活质量之间的关系。

### 改善路径

从城市规划、职住平衡、轨道交通、弹性工作和企业通勤支持等角度提出可能的改善方向。

## 数据来源

网页使用和引用的主要公开资料包括：

- 中国城市规划设计研究院《中国主要城市通勤监测报告》系列资料。
- 国家统计局《中国统计年鉴》中的行业就业与工资数据。
- 页面注明来源的公开调查和微信公众号图表资料。

本项目是课程数据新闻作品。页面中的案例叙事用于帮助理解数据，不代表对所有城市和全部青年群体的普遍推断；具体数值应结合网页标注的来源、统计年份和样本口径阅读。

## 本地运行

项目没有 npm 构建步骤。克隆仓库后，在项目根目录启动静态服务器：

```bash
git clone https://github.com/thefuckbear/data_news_work.git
cd data_news_work
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

也可以直接打开 `index.html`，但部分浏览器会限制本地文件加载；使用静态服务器更稳定。

## 浏览建议

- 建议使用 Chrome、Edge 或 Firefox 的较新版本。
- 页面包含长篇滚动叙事和较大图表，桌面端阅读体验更完整。
- 交互图表可以悬停查看信息；部分大图支持缩放、移动或全屏查看。
- 移动端可阅读正文，但复杂可视化建议横屏或改用桌面端查看。

## 研究边界

- 数据跨越不同年份、城市层级和调查来源，不能脱离来源口径直接比较。
- 部分公开调查数据来自二次传播页面，正式学术引用时应进一步回溯原始报告。
- 项目用于数据新闻叙事和课程展示，不构成城市规划或就业决策建议。
